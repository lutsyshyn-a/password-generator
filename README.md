# Генератор паролів і ключів

Односторінковий додаток: Vite + React + TypeScript. Без бекенду, генерація через `crypto.getRandomValues`.

## Запуск

Версію Node.js 24 задано в `.nvmrc`.

```bash
npm ci
npm run dev      # розробка на http://localhost:5173
npm run build    # збірка в dist/
npm test
```

## Публікація на Netlify

1. `git init && git add . && git commit -m "init"`
2. Створіть репозиторій на GitHub, `git remote add origin <url>`, `git push -u origin main`
3. Netlify → Add new site → Import from Git → оберіть репозиторій.
   Налаштування підтягнуться з `netlify.toml` (build: `npm run build`, publish: `dist`).

## Формати генерації

- **Пароль.** Результат містить щонайменше один символ із кожного ввімкненого набору. Символи для URL (`- _ . ~`) і додаткові спецсимволи (`! @ # $ % ^ & * + = ?`) вмикаються окремо. Ентропія враховує лише комбінації, що задовольняють ці умови.
- **Hex і Base64URL.** Довжина задається в байтах. Наприклад, 32 байти дають 64 шістнадцяткові символи або 43 символи Base64URL без доповнення.
- **Парольна фраза.** Слова незалежно вибираються з локального англомовного словника та розділяються пробілами. За замовчуванням фраза має шість слів, що дає приблизно 77 біт ентропії.

Парольні фрази використовують [EFF Long Wordlist](https://www.eff.org/files/2016/07/18/eff_large_wordlist.txt) від Electronic Frontier Foundation за ліцензією [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). У локальній копії збережено всі слова, а індекси для гральних кубиків прибрано.

## Структура

- `src/lib/generator.ts` — генерація (Web Crypto, без зміщення), оцінка надійності
- `src/hooks/useSettings.ts` — налаштування в `localStorage` (самі паролі не зберігаються)
- `src/components/` — `OutputCard`, `LengthControl`, `Toggle`
- `public/_headers` — заголовки безпеки для Netlify (CSP тощо)

## Клавіші

Натисніть `R`, коли у фокусі кнопка «Згенерувати», або `C`, коли у фокусі кнопка «Скопіювати». Команди прив’язані до фізичних клавіш і працюють незалежно від розкладки.
